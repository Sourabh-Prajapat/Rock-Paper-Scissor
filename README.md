# ✊ Rock Paper Scissor

A fun, interactive, and browser-based **Rock Paper Scissor Game** where you play against the computer. Choose your move, let the computer make its choice, and see who wins!

## 🌐 Live Demo

🎮 **[Play the Game](https://sourabh-prajapat.github.io/Rock-Paper-Scissor/)**

## 📸 About the Project

Rock Paper Scissor is a simple and entertaining game developed using **HTML, CSS, and JavaScript**.

The player can choose Rock, Paper, or Scissor, while the computer randomly selects one of the three options. The game compares both selections and instantly announces the result.

After every round, the scoreboard automatically updates and displays the latest scores along with the selected figures of both the player and computer.

## ✨ Features

- 🎮 **Interactive Gameplay** – Play against the computer with three different choices.
- 🤖 **Random Computer Moves** – Computer randomly selects Rock, Paper, or Scissor.
- 🏆 **Winner Detection** – Automatically determines the winner based on game rules.
- 📊 **Live Scoreboard** – Updates the scores after every round.
- ✊ **Selected Moves Display** – Shows the choices made by both the player and computer.
- ⚡ **Instant Results** – Displays Win, Lose, or Draw immediately after each selection.
- 🎨 **Beautiful UI** – Clean design with colorful game icons and a soft gradient background.
- 🔄 **Continuous Gameplay** – Play multiple rounds without refreshing the page.

## 🕹️ How to Play

1. Open the game using the Live Demo link.
2. Select **Rock, Paper, or Scissor**.
3. The computer randomly chooses its move.
4. Both selections are displayed on the screen.
5. The game compares the choices and announces the winner.
6. The scoreboard updates automatically.
7. Keep playing and try to beat the computer!

## 📋 Game Rules

| Player's Choice | Computer's Choice | Result |
|:---:|:---:|:---:|
| ✊ Rock | ✌️ Scissor | You Win |
| ✊ Rock | 📄 Paper | Computer Wins |
| 📄 Paper | ✊ Rock | You Win |
| 📄 Paper | ✌️ Scissor | Computer Wins |
| ✌️ Scissor | 📄 Paper | You Win |
| ✌️ Scissor | ✊ Rock | Computer Wins |
| Same Choice | Same Choice | Draw |

## 🏅 Scoring System

| Game Result | Score Update |
|---|---|
| Player Wins | Player's Score +1 |
| Computer Wins | Computer's Score +1 |
| Draw | No Change |

The scoreboard keeps track of both scores and updates after every round.

## 🛠️ Technologies Used

- **HTML5** – Structures the game interface.
- **CSS3** – Handles styling, layout, colors, and visual effects.
- **JavaScript** – Implements game logic, random selection, winner detection, and dynamic score updates.
